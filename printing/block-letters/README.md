
# block-letters

[ASCII art](https://en.wikipedia.org/wiki/ASCII_art) is a way of creating images using the individual characters from a keyboard.

For example, the following is ASCII art of some letters from the English alphabet.

![A grid showing eight 5x7 matrices arranged in two rows of four matrices each. Each matrix has column headers numbered 1 through 5 and row headers numbered 1 through 7. The matrices contain letters A through H, respectively, with each letter appearing in different patterns within its matrix. Matrix A shows the letter A in various cells, matrix B shows the letter B in various cells, and so on. Each letter's placement within its respective matrix creates a larger pattern of that letter across the 5 columns and 7 rows. e.g., the A matrix uses the capital character ](https://content.codecademy.com/courses/learn-cpp/hello-world/block-letters.png)

The letter F is made up of five characters in the first row, one character in the second and third rows, three characters in the fourth row, and one character in the fifth, sixth, and seventh rows. These characters, when viewed together, look like the letter F.

In this project, we will write a Python program that displays the initials of your name in block characters to get an introduction into the world of ASCII art.

## Setting Up

1. Let’s start by writing two comments:

   1. your full name
   2. a fun fact about yourself

## Creating Art

2. Now that we have our name down, let’s output our first initial!

First, take a look at [this alphabet](https://content.codecademy.com/courses/learn-cpp/hello-world/block-letters-hint.png) to find your initials. Notice how each block letter is 7x5 and formed by the letter itself. If this alphabet doesn’t work for your name, this is your chance to get creative!

Try printing out the first character of your first or given name as a block character!

> Note: An alternate option for this task is to print out your first or given name instead of using ASCII art to write your initial!

Finally, select “Save” to run your program and view your printed ASCII art!
